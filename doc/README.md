## 📑 Guias Disponíveis

- [**Arquitetura de Competências e Esteira de Documentos**](arquitetura-competencias-modulos-documentos.md): Detalhamento do fluxo de competências mensais, troca de documentos (DF-e, OFX, folha) e permissões por porte empresarial.
